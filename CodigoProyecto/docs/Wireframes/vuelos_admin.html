Reglas Operativas Clave:
• US-05 (Modificación Puntual): El cambio de horario/avión aplica solo a la fecha elegida. Si hay ventas previas y cambia el horario, se notifica por email (RF-10). No se permite asignar un avión con menor capacidad a las ventas.
• US-06 (Cancelación): Requiere confirmación explícita. El vuelo pasa a estado Cancelado (no se borra físicamente). Si hay pasajes vendidos, dispara notificación de contingencia (RF-10).
• US-12 (Modificación de Tarifas): Actualiza la oferta para compras futuras; no altera las ventas emitidas previamente.
